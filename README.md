# 💰 SaveMoney

> Um aplicativo mobile desenvolvido com React Native e Expo para ajudar você a gerenciar suas finanças pessoais de forma simples, prática e eficiente.

---

## 📱 Sobre o Projeto

O **SaveMoney** foi criado para ser uma ferramenta de controle financeiro direto ao ponto. Utilizando o ecossistema React Native/Expo, o aplicativo oferece uma estrutura otimizada para dispositivos móveis, focando em uma experiência de usuário fluida e organizada.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

- **[React Native](https://reactnative.dev/)** - Framework para construção de aplicações móveis nativas.
- **[Expo](https://expo.dev/)** - Plataforma para desenvolvimento universal com React Native.
- **[JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)** - Linguagem principal do projeto.
- **[Yarn](https://yarnpkg.com/) / [npm](https://www.npmjs.com/)** - Gerenciadores de pacotes.
